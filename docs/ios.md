# Dolphin Pod for iPhone

The iPhone app is a chat client for the same pod: the chat list, streamed thinking, agent colors and gradients,
`@mention` autocomplete, photos and files, and a settings screen for sync, providers and per-agent models. Tap or
long-press an agent's avatar for its card (job, all-time tokens, thinking and working time).

## Getting your pod onto the phone

**Settings → Sync → Turn on sync** with the same database URL and passphrase as your computer. Chats, agents, your
roles and name, provider keys and usage totals arrive encrypted and are decrypted on the phone.

## Which model answers

Local models cannot be reached from a phone. An agent whose computer model is local shows *Runs on your computer*;
give it an **iPhone model** in **Settings → Agents** (any cloud reasoning model from a provider with a key), or send
the request to your desktop with [remote control](remote-control.md). Overrides sync, so you set them once.

## Updates

*About → Check for updates* reads the same release manifest as the desktop apps.
