# Getting started

1. **Connect a provider.** On first launch, pick Ollama or LM Studio (local) or paste an OpenRouter key.
   Everything else is in **Settings → Providers**.
2. **Give your agents a model.** Choose one reasoning model for everyone, then fine-tune individual agents in
   **Settings → Agents**. Only reasoning models are listed.
3. **Say hi.** Open any chat and type. Roger acknowledges right away, routes your message, and the right
   specialist answers. Type `@` to talk to an agent directly.

Tips:

- Pasting more than 6,000 characters turns the text into a `.txt` attachment.
- Drop files or images onto a chat to attach them.
- Press `Esc` to stop agents that are working.
