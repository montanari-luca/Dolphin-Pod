# Permissions and workspaces

Give a chat a **workspace folder** (chat settings) to let agents work with files there.

- **Read-only** (default, and always while planning): read, list and search files.
- **Full agentic**: also write and edit files and run commands, only inside the workspace.

A plan is approved with the **Approve plan** button or by replying with an approval; Lincoln then grants the
planner full permissions and the implementation starts. You can also toggle an agent's permission from the
members panel. Every change is announced in the chat, every action is listed in the **Action log**, and
permissions are enforced by the app itself, not by prompt instructions.
