# Dolphin Pod website (Phase 3)

Static product site built with **Astro + Tailwind CSS + Motion**, managed with **pnpm** as part of the
workspace. `public/` already holds the favicons, touch icon, PWA icons and og-image, generated by
`packages/brand/scripts/make_icons.py`.

The full build plan is in [`implementation/Phase03.md`](../../implementation/Phase03.md).
